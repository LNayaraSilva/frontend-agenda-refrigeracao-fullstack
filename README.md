# ❄️ Agenda de Serviços de Refrigeração

Sistema web desenvolvido para **agendamento de serviços de refrigeração**, permitindo cadastrar, editar e excluir solicitações de forma simples, rápida e organizada.

---

## 🌐 Demonstração

👉 https://agendaservicosrefrigeracao.netlify.app/

---

## 🚀 Funcionalidades

- 📅 Cadastro de agendamentos  
- ✏️ Edição de registros  
- 🗑️ Exclusão de agendamentos  
- 🔄 Atualização da lista em tempo real  
- 📱 Interface responsiva (mobile e desktop)  
- ❄️ Tema voltado para serviços de refrigeração  
- ⚡ Aplicação PWA (funciona offline)  

---

## 🧾 Informações do agendamento

- Nome do cliente  
- Endereço  
- Telefone  
- Tipo de serviço  
- Data e horário  
- Observações  

---
